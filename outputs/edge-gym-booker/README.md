# 上海交大体育场馆 Edge 自动预约工具

这个工具使用电脑上已有的 Microsoft Edge，并保存一份独立登录状态。它会在指定时间刷新预约页，按优先顺序寻找场地、选择时段、提交订单，并在支付界面停止。

它不会读取或保存密码，也不会绕过滑块验证码。网站要求滑块时，程序会响铃并停在页面上，请手动完成。

## 1. 安装

在本文件夹打开 PowerShell：

```powershell
npm install
Copy-Item config.example.json config.json
```

## 2. 登录并保持认证

```powershell
npm run login
```

Edge 打开后，在网页中完成交我办登录；脚本检测到“我的订单”和预约网格后会自动关闭窗口。登录状态会保存在本文件夹的 `.edge-profile` 和 `.auth-state.json` 中，不使用你日常 Edge 的默认配置。这些文件含登录 Cookie，不要公开分享。

载入 Cookie 不代表认证仍然有效。场馆接口返回 HTTP 401、业务码 401，或页面出现登录入口时，脚本会在提交订单前优先点击可见的“校内人员登录”，利用现有交我办会话恢复。恢复成功必须同时验证登录状态、场地网格和接口，然后保存认证并清零失败计数。此后再次过期仍可再次恢复，不受“一次登录”限制。临时恢复失败继续刷新重试；连续 3 次恢复失败，或明确出现密码、验证码等人工验证要求时停止。仅有“我的订单”的空页面不算恢复成功。

恢复认证只在标签页首次进入时补入缺失信息，保留浏览器现有 Cookie 和网页更新的令牌，避免页面刷新时把新令牌覆盖回旧值。每次成功预检及选场地后都会保存最新认证信息。提交后尚未确认支付界面时也允许重新登录、刷新选场并再次提交。

只检查认证并保存更新，不选择场地或下单：

```powershell
npm run auth
```

## 3. 设置预约

编辑 `config.json`：

- `activityType`：页面顶部的场地类型；留空表示使用默认第一个类型。
- `targetDate`：预约日期；设为 `"auto"` 时按中国日期自动选择七天后，也可以填写 `YYYY-MM-DD`。
- `timeSlots`：一个或多个连续/非连续的单小时时段，例如 `"18:00-19:00"`。
- `preferredCourts`：场地名称关键词，按顺序优先。例如 `["1号", "2号"]` 表示先找名称含“1号”的场地，再找“2号”，都没有时才选择其他可用场地。空数组 `[]` 表示任意可用场地。
- `excludedCourts`：永远不选的场地名称关键词。例如钢琴预约可设置 `["无钢琴"]`。
- `sameCourt`：多个时段是否必须是同一个场地。
- `releaseAt`：设为 `"auto"` 时，自动按“目标日期前 7 天中午 12:00（中国时间）”计算。设为 `null` 表示立即开始，也可手填带 `+08:00` 的时间。
- `retryIntervalMs`：中国时间中午 12 点前失败后的等待间隔，最低 1000 毫秒；12 点起固定等待 2000 毫秒（2 秒）后刷新。页面加载耗时另计。
- `maxAttempts`：手动运行的最多尝试次数，最高 120；定时运行持续重试至 12:05，不受此次数限制。
- `dryRun`：`true` 只选中不提交；确认配置无误后改成 `false` 才会真实创建订单。
- `paymentTimeoutMs`：提交订单后等待订单详情和支付界面的最长时间；建议保留 `90000`（90 秒）。
- `keepOpenMinutes`：完成、报错、截止或出现验证码后，Edge 保持打开的分钟数，默认为 60 分钟。

建议先用 `dryRun: true` 演练一次。配置完成后可检查：

```powershell
npm run check
npm run show-time
npm test
```

## 4. 开始预约

```powershell
npm run book
```

程序应在 `releaseAt` 之前启动。电脑需要保持开机、网络正常，且不要手动关闭自动打开的 Edge 窗口。

如果需要真实提交，务必先把 `dryRun` 改成 `false`。完整流程为：选择场地 → 核验活动日期和预约摘要日期 → 打开预订须知 → 勾选须知 → 再次核验日期并提交订单 → 如出现订单详情则点击“立即支付/去支付” → 识别支付界面后停止。未识别到支付页、加载超时或网站拒绝提交时，重新加载并重试选场和提交。工具不会点击支付界面内的付款确认按钮。

成功标准是进入支付界面并生成 `logs/*-payment-ready.png`。仅进入订单详情页不算完成。每轮重试前也会检查是否已有迟到的支付页；如果出现则停止重试。提交结果不明时按用户要求允许再次提交，重复订单由网站判定。定时任务仍在 12:05 停止新增尝试和提交。

提交时监听本轮 `ConfirmOrder` 响应：网站明确返回失败（例如业务码888人数已满、500已被预定）后立即结束支付等待，按两秒间隔重新选场。接口成功但未到支付页记为支付等待超时；没有成功或失败证据时记为结果未知，不再记作订单已创建。定时模式的支付等待也受12:05截止时间限制。重试前通过“上一步”关闭残留预订须知；已勾选的须知不重复点击，提交前再次检查勾选状态。

开发验证：`npm run test:submission` 检查接口拒绝、迟到响应和结果分类；`npm run test:submission-browser` 使用临时 Edge 和全部拦截的模拟网络检查下单交互，不读取个人认证，不向真实网站下单。

当前默认配置为：中国时间周日预约七天后的气膜体育中心羽毛球；周一、周二、周四至周六预约七天后的学生中心健身房，周三不执行定时预约。均为 17:00–18:00，任意可用场地。周日场馆由 `config.json` 的 `sundayBooking` 配置覆盖；成功进入支付界面后停止，不会自动付款。

## Windows 自动定时启动

如果已经在 Codex 中启用了同名循环任务，请不要再安装 Windows 定时任务，否则同一时间可能启动两份预约程序。

先完成一次 `npm run login`，并确认 `config.json` 中 `targetDate` 与 `releaseAt` 都是 `"auto"`。然后在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install-schedule.ps1
```

它会创建一个循环 Windows 定时任务，除周三外每天 11:59:50 启动工具；工具本身等待到中午 12:00，预约七天后 17:00–18:00 的场地：周日为气膜体育中心羽毛球，周一、周二、周四至周六为学生中心健身房，周三跳过。任务只会在当前用户已登录时运行，因为预约过程中可能需要显示 Edge 和人工完成滑块。

任务使用 `--scheduled` 参数并关闭“错过后尽快运行”。定时启动仅接受中国时间 11:59:50 至 12:05 之前，预约从 12:00 开始；12:05 起跳过。启动、每轮重试和提交订单前都会检查窗口，因此等待期间电脑休眠、下午恢复也会跳过。手动执行 `npm run book` 不受这个定时窗口限制。

正常重试保留当前网页和登录状态，优先切换到其他日期，再切回目标日期触发更新，不再每轮整页刷新。项目切换后先等日期列表和默认网格接口完成，避免迟到响应把日期重置为当天。切到目标日期后，必须等该次请求返回，并核对请求日期、项目、返回状态和余量与页面格子一致，且界面连续稳定至少 0.8 秒、没有加载遮罩，才判断余量和选场。等待最长 30 秒，超时标记为“数据未就绪”，而不是“没有场地”。认证检查只等待用户/场馆认证接口，不再被公告等非关键接口拖住。页面离开预约地址、需恢复登录或多次卡住重开浏览器时才重新导航。12 点起每轮失败后等待 2 秒；定时运行在 12:05 截止。

每次运行在 `logs` 下保存同名前缀的文字日志和 JSONL 诊断日志。新增网格请求编号、日期/项目/场馆参数、接口各格子的状态与余量、数据稳定时间、目标时段的页面样式和余量，以及正在等待的请求。截图优先覆盖完整网格，包括17点；相同页面状态最多每30秒保存一次，提交前后仍保存。每轮状态文字和目标格子数据照常记录；不再保存大段场馆规则文本。浏览器重开后写入同一份日志；不记录 Cookie、密码、请求头或完整业务数据。

日志和快照仅保留最近72小时：每次预约启动自动清理，另有 Windows 任务 `SJTU-Gym-Booker-LogCleanup` 每天03:00清理，错过时在可运行时补做。清理只删除本工具 `logs` 文件夹内过期的日志和图片等诊断文件，不进入子目录，不删除登录状态或浏览器配置。删除不经过回收站。

查看任务：

自动重开机制仅在北京时间 12:00 起启用，12 点前的失败不计入重开计数。连续 3 次可重试的加载或提交错误时，自动关闭本次预约专用浏览器，再重新打开并继续预约；每次运行最多重开 2 次。单纯没有可用名额时继续普通刷新。重开仍遵守 12:05 截止时间；手动中断脚本会停止任务。

```powershell
Get-ScheduledTask -TaskName "SJTU-Gym-Booker-Recurring"
```

电脑应保持登录、联网；电池供电时也允许启动，运行中拔掉电源不会停止任务。脚本启用了“唤醒电脑运行”，但还需要 Windows 电源设置允许唤醒计时器。
